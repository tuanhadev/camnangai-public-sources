# camnangai — public sources

Runnable sample projects from the step-by-step guides on
[camnangai.com](https://camnangai.com). Each folder is the finished code for
one article, so you can clone and run it instead of copying snippets by hand.

| --- | --- |

| [`coding-agent-demo`](./coding-agent-demo) | [Hướng dẫn tự xây dựng một coding agent tối giản](https://camnangai.com/ung-dung-ai/lap-trinh-vien/tu-xay-dung-coding-agent) · [How to Build Your Own Coding Agent](https://camnangai.com/en/for/developers/build-your-own-coding-agent) |

Each project has its own README with setup and run instructions.
